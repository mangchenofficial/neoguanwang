标题: MXOS 1.2.0：一个藏在浏览器里的桌面系统

日期: 2026年5月31日

分类: 项目介绍

标签: MXOS, WebOS, 前端



从第一次把网页做成操作系统界面试一试，到后来真的在浏览器里跑起一个完整的桌面环境，这条路我走了很久。MXOS 1.2.0 是我最近完成的一个纯前端 Web OS，它不是简单的模仿，而是可以真正安装应用、管理文件、设置壁纸和主题的桌面系统。



一开始我只是想做几个好看的窗口，让它们能拖动、最大化。但写着写着就停不下来：桌面图标要能拖拽排列，任务栏要显示运行中的应用，文件系统要能存东西，还要有一个应用安装器，支持 .mx 格式的第三方包。于是我用 HTML、CSS 和原生 JavaScript 一步步把这些功能堆了出来，最后有了你现在看到的 MXOS。



它的核心功能包括：基于 IndexedDB 的真实文件系统（C盘/D盘、回收站、文件夹层级）；多窗口管理（拖动、缩放、最大化、最小化，动画流畅）；内置应用（此电脑、回收站、喜edge多标签浏览器、喜音乐、喜Office、设置中心、应用安装器）；个性化（静态壁纸、视频壁纸、强调色、透明效果、亮度与夜间模式）；甚至还可以搜索在线音乐、播放本地音频。



最让我兴奋的是应用安装器的实现。你可以拖放一个 .mx 安装包，系统会解压 manifest 和 app.bin，然后自动在开始菜单和已安装列表里出现这个应用。第三方应用可以通过 MXOS 提供的 API 控制窗口、读写本地存储、发通知和对话框，就像一个真正的操作系统一样。



· 真正的窗口系统：支持拖动、最大化、最小化、关闭，多窗口分层管理，动画流畅。
· 桌面图标与任务栏：图标可拖拽排列、自动网格吸附，右键菜单支持刷新、新建文件夹、个性化入口。
· 应用生态：内置此电脑、回收站、喜edge浏览器、喜音乐、喜Office（文档/表格/演示）、设置中心、应用安装器。
· 应用安装器：支持 .mx 格式的安装包，拖拽或选择文件即可安装第三方应用，安装后出现在开始菜单和已安装列表，支持卸载与启动。
· 个性化定制：静态壁纸/视频壁纸、强调色切换、透明效果、动画开关，壁纸亮度自适应文字颜色。
· 真实的文件系统：基于 IndexedDB，支持 C盘/D盘、文件夹层级、回收站逻辑，可创建和删除文件。
· 音乐模块：搜索并播放在线歌曲，支持本地音频文件，带进度条、播放列表、分页，记忆播放状态。
· 设置中心：屏幕亮度、显示比例、夜间模式、音量、通知、电源模式、主题、日期时间、网络与 Wi-Fi 模拟、辅助功能等。
· 浏览器套娃：多标签页、前进后退、刷新、地址栏输入，内置常用站点快捷方式。

技术亮点

· 完全运行在浏览器中，无需后端服务。
· 使用 JSZip 解压安装包，localStorage 和 IndexedDB 存储应用配置与文件系统。
· 第三方应用通过 app.bin 注入执行，提供标准 API（窗口操作、存储、通知、对话框等）。
· 响应式窗口缩放，适配不同分辨率。

适合谁用

· 对操作系统实现感兴趣的前端开发者。
· 喜欢在网页中体验桌面交互的极客玩家。
· 需要轻量级在线演示或个人项目展示的创作者。

体验入口

打开浏览器，进入 MXOS 1.2.0 页面，一个完整的桌面系统就启动了。
你可以拖拽图标、安装应用、更换壁纸，甚至用内置浏览器去访问其他网站。

它不是概念图，不是视频演示，而是一个真的可以动手操作、可以扩展的 Web OS。
